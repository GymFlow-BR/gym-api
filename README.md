# GymFlow API

API backend do GymFlow, MVP de uma plataforma para academias, professores/personais e alunos.

## Tecnologias

- Java 21
- Spring Boot
- Maven
- PostgreSQL
- Flyway
- Spring Data JPA
- Bean Validation
- Lombok

## Como rodar localmente

No momento, o projeto foi criado e validado com:

mvn clean install
